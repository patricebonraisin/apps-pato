Comment utiliser Assistant Maison

Connectez votre Home Assistant, retrouvez vos favoris et gardez le contrôle de votre maison. Voici les réponses aux questions les plus fréquentes.

Bien démarrer

Assistant Maison fonctionne avec une installation Home Assistant déjà configurée : elle ne remplace pas Home Assistant et n’ajoute pas directement d’appareils. Un mode d’emploi complet est aussi disponible directement dans l’application, depuis Réglages → Mode d’emploi.

1. Connecter Assistant Maison à Home Assistant

Dans Réglages → Connexion Home Assistant, renseignez l’adresse de votre installation (par exemple http://homeassistant.local:8123) ainsi qu’un jeton d’accès longue durée, puis appuyez sur Tester la connexion.

2. Où trouver ou créer un jeton d’accès longue durée ?

  1. Ouvrez Home Assistant et accédez à votre profil utilisateur.
  2. Descendez jusqu’à la section « Jetons d’accès longue durée ».
  3. Choisissez « Créer un jeton » et donnez-lui un nom, par exemple « Assistant Maison ».
  4. Copiez le jeton affiché : Home Assistant ne l’affiche qu’une seule fois.
  5. Collez-le dans le champ « Jeton d’accès » de l’application.

3. Accès depuis l’extérieur de votre domicile

Une adresse locale (comme homeassistant.local) fonctionne uniquement lorsque votre iPhone est connecté au même réseau que Home Assistant. Pour piloter votre maison depuis l’extérieur, votre Home Assistant doit proposer un accès distant sécurisé, par exemple via Home Assistant Cloud (Nabu Casa) ou une autre méthode d’accès distant de votre choix. Ce n’est pas obligatoire : l’adresse locale suffit si vous n’utilisez l’application que chez vous.

4. Favoris et appareils masqués

Ajoutez une étoile à un appareil dans l’onglet Appareils pour le retrouver rapidement sur l’écran d’accueil. À l’inverse, masquez les appareils ou entités que vous ne souhaitez pas voir : ils restent accessibles à tout moment depuis Réglages → Appareils masqués, où vous pouvez les réafficher.

5. Verrouillage Face ID

Vous pouvez protéger l’accès à l’application avec Face ID, Touch ID ou le code de votre iPhone en activant l’option dans Réglages → Verrouillage. Si l’authentification échoue ou n’est pas configurée, un bouton « Déverrouiller » reste disponible pour réessayer.

6. Un appareil apparaît indisponible

Cela signifie que Home Assistant ne transmet pas actuellement son état. Essayez d’actualiser l’application, puis vérifiez l’appareil et son intégration directement dans Home Assistant si le problème persiste.

7. Caméras

Assistant Maison affiche l’image disponible pour toute entité caméra transmise par Home Assistant. La qualité et la disponibilité d’un flux dépendent de votre intégration caméra (Ring, Reolink, UniFi Protect, Frigate, etc.).
