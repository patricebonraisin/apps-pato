JOUER À PULSE

Comment marquer des points ?

Touchez l’écran lorsque le cercle coloré rejoint la cible lumineuse. Plus votre timing est précis, plus votre combo et votre score progressent.

Quel mode choisir ?

Le mode Classique est le défi principal. Le mode Zen permet de s’entraîner sans fin de partie sur un raté. En Chrono, vous avez 60 secondes pour marquer le plus de points possible. Le Défi du jour propose le même déroulé à tous les joueurs, avec une tentative quotidienne.

Où retrouver mes records ?

Depuis l’écran d’accueil, ouvrez les statistiques pour consulter vos meilleurs scores. Si Game Center est connecté, vous pouvez aussi comparer vos performances dans les classements.

QUESTIONS FRÉQUENTES

Le son ou les vibrations ne fonctionnent pas.

Vérifiez d’abord les réglages de Pulse. Assurez-vous ensuite que le mode silencieux, le volume de l’appareil et les réglages système d’accessibilité ne désactivent pas ces retours.

Mon score ne se synchronise pas avec Game Center.

Connectez-vous à Game Center dans les réglages iOS, puis relancez Pulse. Une connexion internet peut être nécessaire pour envoyer les scores vers les classements.

Comment recommencer le tutoriel ?

Depuis l’écran d’accueil, ouvrez les réglages, puis choisissez l’option permettant de revoir le tutoriel.

Toujours besoin d’aide ?

Décrivez-nous votre question et indiquez la version de Pulse utilisée. Nous ferons notre possible pour vous répondre rapidement.
